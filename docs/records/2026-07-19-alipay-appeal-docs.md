## 一、核查与冻结的法律依据 —— 「交易核查处理规则」

URL: https://opendocs.alipay.com/b/03ai9x

> 支付宝会对相关交易进行核查。**核查期间，支付宝会通过电话或邮件要求被核查账户持有人举证**，证据包括但不限于：
> - **物流凭证**
> - 交易过程中阿里旺旺聊天记录截图（非阿里旺旺聊天记录只能作为参考）
>
> 核查期间，被核查支付宝账户及/或账户内资金将受到**限制**。
> **未在指定时间内提供证据，或证据无效、不充分的**，支付宝将采取：关闭余额支付 / 限制收款 / **冻结账户内资金** / 冻结账户 / 停止提供支付宝服务。涉嫌犯罪移交公安。

**关键认知**:
- 资金冻结本质是「核查期临时限制」，不是直接处罚。
- 证据「不充分」才会升级到正式冻结。
- 物流凭证是实物商品的主证据；**线上 SaaS 没有物流凭证，其等价物必须是「可验证、不可篡改、带时间戳的服务交付凭证」** —— 这正是链证存证方案要填的空。
- 阿里旺旺聊天记录只是「参考」，不能作为主证据。

## 二、自助解限通道 —— 「商家安全服务」小程序

URL: https://opendocs.alipay.com/p-helpcenter/02tob7

- 支付宝端内搜「商家安全服务」小程序，直连 / 间连商户 / 服务商都支持。
- 解限操作流程：申请提前解限 → 检测设备安全环境 → 选商户类型 → 选经营场景 → 上传凭证 → 等审核。
- 两种解限方式：
  1. **答题解限**（答对所有题）
  2. **补充凭证解限**（系统按商户情况提示要补什么）← **SaaS 走这条**
- 一般 **24 小时内**出结果，在处罚列表里看申诉状态。

## 三、准入/解限申诉材料清单（最具体的官方字段表）

来源: https://opendocs.alipay.com/p-helpcenter/00zv8q + https://opendocs.alipay.com/p-helpcenter/05g6wy

### 必传照片
1. **商户法人手持营业执照**（必填，无 PS，信息清晰）
2. **商户门店照片**（必填，实体经营地点门头照）⚠️ 纯线上 SaaS 会卡这项
3. **商户法人手持身份证原件**（必填）
4. 商户交易机打小票（选填，实体交易才有）
5. 其他项一/二（选填，如**法人手持承诺合法经营的承诺书**）

### 必填基本信息
- 商户名称、营业执照号、法人身份证号、**结算账户/收款银行卡**
- （间连）商户编号 SMID（16 位数字）、合作伙伴 ID
- 商户经营情况说明（实体：省市区街道 / 线上：行业类目）

### 图片要求
- jpg/jpeg/png，单张 <5MB，无 PS，近期拍摄，清晰。

### 审核时效
- 准入申诉一般 1-3 个工作日。
- 申诉成功后须 7 天内重新进件，间隔 3H。

### 客服热线（进件/准入卡点）
- **95188**（由客服指定专人跟进，无 BD 的平台商用）。
- 商家专线 **4007585858**（每天 8:00-24:00）。

## 四、对 Savvy Agent（线上 SaaS）的落点

### 落点 A —— 「门店照片」这一关的替代物
纯线上 SaaS 没实体门头照，是官方清单硬一项。**实际我们有料**（居民楼小办公室+招牌+视频）：
- 办公地实景照（航海东路 12-4-605）
- 办公地现场法人手持营业执照合照（替代「门店+法人手持营业执照」两项合一）
- 办公地招牌特写 + 室内工作环境视频
- scheng.net 首页截图 / 服务页截图 / 服务协议页截图（证明经营场景是线上 SaaS）
- 办公地房产证或租赁合同（佐证办公地真实）

放「冻结申诉材料包」备用目录，跟备案截图、营业执照、退款政策一起备齐。

### 落点 B —— 链证存证方案填的正是核查期要的「履约类证据」
官方规则明文：核查证据 = 物流凭证 + 聊天记录（参考）。
线上 SaaS 主证据等价物 = 服务器日志 / 套餐激活时间戳 / 用户调用模型日志 / 给 quota 的 ledger 行。

**问题**：库内记录易被自己改，支付宝采信度弱 → 易被判「不充分」→ 升级正式冻结。
**解法**：链证 `deliverOrder` + `deliveryHash` 把线上交付从「易改的库记录」升级到「链上不可篡改凭证」，对应物流凭证的可验证性。
→ 这证明链证存证方案不是过度设计，是 SaaS 在核查阶段交「充分证据」的核心。
→ 等段 2b 沙箱通后补 `deliverOrder` 第 4 步上链。

### 落点 C —— 务必注意「证据不充分 → 升级冻结」递进
官规则死：证据无效/不充分 → 冻结账户内资金/冻结账户。

- 第一次核查：交库截图 → 可能被判「不充分」（库截图易改）→ 已「核查中限制」的基础上第二次升级到正式冻结。
- 交链证浏览器取证截图 + 现场演示枚举 hash 重算对比 → 「充分可信证据」→ 大概率解限。

→ 链证做得越早、沙箱真·手付款跑通（2583-2563 那笔）越早，冻结申诉那天拿真链证给支付宝看越稳。

## 五、两条申诉线别混淆

| 线 | 触发 | 申诉入口 | 要交什么 |
|---|---|---|---|
| **A. 资金冻结/核查申诉** | 账户被风控/限额/冻结可提现 | 商家安全服务小程序 + 95188 / 4007585858 | 主体资质 + 被标订单履约凭证 + 资金流向 + 服务协议 |
| **B. 芝麻信用负面申诉** | 用户投诉「履约记录有误」 | zhima.alipay.com/admin/dissent/index.htm（商家中心-用户申诉，公司账号） | 调查 + 联系用户 + 工单完结（5 工作日不答判输） |

链证对线 A 最有用（防资金冻结）。线 B 是流程问题，靠工单时效和客服，不上链。
